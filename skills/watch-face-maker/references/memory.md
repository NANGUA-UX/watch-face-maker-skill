# 项目记忆格式

在项目根目录维护 `MEMORY.md`，按日期追加以下内容：

```markdown
## YYYY-MM-DD｜项目名称

### 项目与来源
- 目标 Figma 文件和节点：
- 素材来源策略（新建/改造/允许复用/禁止复用）：
- 参考图、采用素材、被替代素材的哈希与去向：
- 规范节点：
- 案例节点：
- 组件库：
- 开发能力、配置和命名文档：

### 用户已确认
- 目标尺寸与屏形；多尺寸任务的源盘及全部目标：
- 语言、主题、单位、AOD、动态字段和特殊需求：
- 本次启用、未请求和明确排除的能力：
- 进度能力的实现模式（state_images/native_continuous）及框架依据：
- 命名模式、序列格式和旧项目迁移状态：

### 制作与修正
- 修改内容：
- 用户反馈：
- 修正结果：

### 验证证据
- 主表盘与缩略图：
- 裸背景源、目标尺寸局部与整盘：
- 草稿可评审、全量生产、用户验收、固件验证：
- AOD亮屏比例：
- 状态、命名和导出检查：
- 未请求能力和排除项检查：

### 待沉淀候选
- 仍需跨项目验证的经验：
```

项目坐标、单次配色和素材属于项目事实。只有在多个项目中重复成立、且会改变后续决策的结论，才提炼进 skill。
