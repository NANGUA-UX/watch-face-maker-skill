# 动画切图

用户明确需要动画时读取本文件；学习案例不自动触发制作。动画是按顺序播放的切图资源，不能只交一张静态图或一个预览视频，也不限定为图标动画。

## 制作前确定

- 记录动画对象、变化方式、触发与重播条件、是否循环及结束停留状态。用户已经说明的内容直接采用，只询问仍影响制作的缺项。
- 对照目标设备开发能力，确定帧率或每帧时长、资源数量和体积限制。案例帧数不能推导播放时长，案例播放规则也不是默认值。
- 分别记录 PNG 磁盘体积和运行资源估算。未压缩像素量可按宽×高×每像素字节数估算；运行内存还取决于同时驻留帧数、解码缓冲、对齐和缓存策略，未知项必须标明，不能把全部帧文件体积或简单乘积当真机内存。设备预算、像素格式或播放参数不明时可先做范围分析和试制，但不能宣布内存或播放验证通过。
- 在生成背景前确定动画区域，以减少内存占用为目标，优先切出覆盖全部帧运动范围及必要效果边缘的最小安全公共区域，其余静态背景单独保留并按原坐标拼合。可以切局部透明帧，也可以切包含固定底图的局部合成帧；确实为全屏动画、无法缩小范围时才切全屏，不为省内存裁掉动画内容。
- 将动画区域及随帧合成的固定内容加入背景拆分清单，按既有流程供用户确认。实时数据和需切换的文字、单位仍保持独立。

## 母件与导出

- 每一帧建立切图组件，展示稿引用其代表帧实例；预览视频用于检查播放效果，不能替代逐帧资源。
- 同一序列使用一致的画框尺寸、裁切范围和定位基准，覆盖整个运动范围。不能逐帧单独贴边裁切导致位置跳动；动画画框不要机械套用文字切图的 4 倍数规则。
- 命名遵循本项目最新命名契约（`Animation` 或 `Ani`），编号连续且唯一。旧案例的 `bg/01`、`Ani_01` 只作为历史事实，不覆盖新项目规则；帧数按实际动画，不固定为 60。
- 按已确认的导出规范设置每帧 PNG 与倍率，通常为独立 1× PNG；检查实际导出尺寸、透明区域和底图合成方式。看见组件或预览视频不代表已经配置或完成导出。

## 验证

- 扫描全部帧的数量、编号、重复名称、画框尺寸与导出设置；对照源动画确认没有漏帧、错序。
- 检查动画框是否带入了可分离的静态区域，能安全缩小时继续收紧；全屏切图记录无法缩小的实际原因。与静态背景拼合时检查坐标、接缝和必要重叠，重叠量按画面确定，不套用案例数值。
- 检查首帧、变化较大的中间帧和末帧，并播放完整序列检查裁切、闪烁、边缘接缝、定位跳动和结束行为。只有要求循环时才检查循环接缝。
- 把序列放回完整表盘，确认时间、实时数据等仍独立更新，背景没有重复留下动画对象造成重影。
- AOD 按独立需求处理，不因亮屏有动画就自动在 AOD 播放。
- 缺少帧率、触发条件或设备验证时明确标为待确认，不能把静态截图或切图检查当作真机播放验收。
