# 规则圆形刻度

制作或修改主表盘外圈、数据子表盘的规则圆形刻度时读取。默认使用可编辑的“同心径向线阵列 → Union → 与圆环 Intersect”结构，不默认改用逐个定位的小矩形、扁平路径或位图。仅在用户明确指定其他结构，或参考形状确实不适用时另选方法，并在项目设计评审中记录具体理由。已有已验收或用户维护区域不因本规则自动重建。

## 制作步骤

1. 从当前设计记录圆心、外半径、内半径、可见刻度数量、起始角、方向、线宽、颜色，以及长短刻度各自的角度集合。参数属于当前项目，不套用示例像素。
2. 建立通过同一圆心的径向直线，按目标角度阵列。完整、等间隔、对径同样式的偶数刻度圈可用 N/2 条贯穿圆心的直线，两端产生 N 个刻度，角度步长为 360°/N。奇数、局部圆弧或对径样式不同时采用单向径向线，避免另一端多出刻度。整圆末端不重复起点；局部圆弧明确端点是否计入数量。
3. 对每个同样式线阵列建立 Union。直线覆盖所需圆环范围；保留原始线节点和旋转关系，不提前 Flatten。角度定位使用共享圆心的变换，不逐个取整旋转后的 X/Y，也不在上一次旋转结果上反复累加变换。
4. 建立同圆心、无填充、向内描边的圆形，直径为两倍外半径，描边宽度为外半径减内半径；由圆环限定刻度径向范围。与线阵列 Union 做 Intersect，并在结果层设置显示颜色。检查工具实际渲染确实使用描边区域参与交集，不把无填充的圆误当成实心圆盘。
5. 长短刻度、粗细或颜色不同的刻度分别建组，各组使用自己的线宽和圆环内半径。短刻度集合排除已由长刻度占用的角度，避免重复覆盖。圆心共用；是否共用外半径按参考设计确定。
6. 在 Figma 中保留 Intersect、Union、径向线和圆环源结构，按职责命名。固定刻度可随背景合成导出，不要求每条刻度独立切图；保留可编辑源与最终导出方式是两个问题。

## 制作后检查

- 回读节点类型和 booleanOperation，确认实际存在 INTERSECT 与 UNION，源线及圆环仍可编辑；仅图层叫“Intersect”不算证据。
- 通过节点及祖先实际变换核对线阵列与圆环共圆心、角度集合及间隔正确，旋转精度使用合理浮点容差；不把旋转产生的小数位置判为错误。
- 以源圆环几何及实际变换确定圆心和半径，不以 Intersect/Union 的可见包围框中心反推。离散刻度没有覆盖极值方向时，交集包围框可以略小于圆环且宽高不同；不能为凑整数或正方形拉伸结果。用户范例用于学习构造方式，源节点的局部偏移仍须测量，不将其照搬为标准值。
- 同组可见刻度具有一致内外半径和线宽；检查合成后实际可见数量，而不是只数线节点。核对端点、长短刻度交界以及有意留空处，没有双画、遗漏或多余对径刻度。
- 同时查看目标原生尺寸和放大局部，检查圆周边缘、抗锯齿、粗细及裁切。结构正确不替代视觉检查，外观相似也不替代要求的源结构。
- 在项目记录中保存构造节点 ID、参数、结构回读和对应截图。默认方法被无依据替换时判失败；缺少回读或视觉证据时记未验证。当前通用校验器未必覆盖上述检查，必须实际核对，不能因其他自动检查通过就宣称本项通过。
