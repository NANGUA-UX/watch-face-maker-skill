# 整表 MP4

将当前亮屏的完整画面和绑定的 60 帧动画合成为一个原生尺寸的 H.264 MP4，更新在同一规格的视频展示位。帧率取制作时登记的值。

## 设计师

1. 第一次在本机使用时，将插件目录保存在固定位置。在 Figma 桌面端选择 **Plugins → Development → Import plugin from manifest…**，打开其中的 `manifest.json`。
2. 首次在旧动态稿上，选中原亮屏或原视频展示位，从 **Plugins → Development → 整表 MP4 → 更新整表 MP4** 运行一次。插件把原实例原位移入固定的「亮屏」外框，并注册右侧按钮。已有固定画框会直接复用。
3. 改完表盘，选中整个**亮屏外框**，在右侧「工具」点 **更新整表 MP4**。框内的亮屏实例可以重置，也可以换成同一主组件的同尺寸实例。放在外框里的独立图标也会进入视频。视频展示位同样支持更新。
4. 开发在 **Dev Mode** 选中展示区的视频图层，点击右侧视频的下载按钮即可获得原文件。下载已经回填的视频无需安装插件。

每个外框应有唯一的正式亮屏实例。出现重复实例、缺帧或渲染期间替换亮屏时，插件会说明原因并保留原视频。编码成功但回填失败时，窗口提供「保存 MP4」。

如果分离嵌套实例后动画层的 ID 变了，插件会在当前亮屏实例内查找本配色的 `Ani/000` 母件。只要仍有唯一一个该母件的实例，就可以继续更新。

## 重新绑定

自动识别失败后会打开「重新绑定」面板，保留能找回的图层和原帧率。也可以从 **Plugins → Development → 整表 MP4 → 重新绑定** 主动打开。使用旧安装包的同事需要用新版文件覆盖原插件目录，并从新包的 `manifest.json` 重新导入以刷新菜单。

1. 如果只有动画层失效，在左侧图层列表展开亮屏，选中实际播放动画的首帧实例或图片占位，在「亮屏内的动画图层」一行点 **使用选中**。
2. 如果重建了整套稿，依次指定完整亮屏、亮屏内的动画层、切图区的 `Ani/000` 主组件、同尺寸的视频展示位。插件会按名称收集同一套 `000–059`。有遮在动画上方的高清替身时选中对应矩形，原替身已移除时点 **清空**。新绑定预填 30 fps，可按规格修改。
3. 点 **保存绑定并导出 MP4**。绑定保存在 Figma 文件里，下次继续点 **更新整表 MP4**。取消或选择校验失败会保留原绑定和原视频。

## 制作与维护

每个动态规格绑定一次。制作步骤和字段见 Skill 的 `references/animation-assets.md`。插件在当前亮屏的临时副本中切换动画槽，按原层级和裁切导出每张完整画面，黑底合成为 MP4。压缩、编码均在本机执行，每次更新消耗 0 个模型 token。原生尺寸需为偶数宽高。

维护源码更新编码器或插件代码后，在本目录构建。最后一条测试命令在包含测试目录的维护仓库中运行。

```sh
npm ci
npm run build
node --test ../../../tests/watch_preview.test.cjs
```

安装时保留此目录中的文件。运行时使用 `manifest.json`、`code.js` 和 `ui.html`，第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。编码器锁定为 h264-mp4-encoder 1.0.12，MIT 声明随 UI 内嵌。上游项目提供其 minih264 和 libmp4v2 构建源码及授权信息。[编码器源码与许可](https://github.com/TrevorSundberg/h264-mp4-encoder)
