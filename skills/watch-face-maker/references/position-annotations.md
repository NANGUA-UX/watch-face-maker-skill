# 切图区位置标注

适用于本项目已有的指针、进度和旋转时间数字。图面由真实资源、必要基准与读数组成；完整开发参数保留在项目清单，不把参数表堆在画面上。指针包含本项目已有的AOD和数据指针；不为标注新增功能或资源状态。

## 共用结构

1. 读取当前母件、正式显示实例和全部相关变换，确定切图尺寸与实际轴心。按目标屏形、原生尺寸和圆角建立不导出的标注FRAME，放在切图资源SECTION内；已有标注定向更新，保留母件ID和引用。
2. 使用当前切图母件的真实1×实例；宽高及内部内容均与母件一致，不重绘、不转曲、不用缩放展示替代目标规格母件。标注实例保持零位，通过`center - pivot`定位；正式显示来源另行登记，不能拿标注实例冒充显示实例。
3. 在标注FRAME的实际`guides`中设置经过轴心的水平原生guide，使用目标局部坐标。辅助LINE、虚线、矩形或文字不能代替guide。不额外绘制轴心圆、十字或圆点。
4. 尺寸线及起止辅助线采用原生`LINE`或开放`VECTOR`，`fills=[]`、描边2px；VECTOR回读实际开放拓扑，不以节点名称或外框形状证明。指针和旋转时间数字的尺寸线为红色；不使用填充矩形模拟尺寸线。
5. 亮色元素用不透明`#000000`标注底，深色元素用不透明`#FFFFFF`标注底。元素同时包含深浅结构、透明开口或复杂效果时提供深浅底对照，分别登记标注FRAME；不能只看一种底色认定边缘完整。底色只作用于标注FRAME，外层表盘SECTION的`#9B9B9B`和切图资源SECTION的`#676767`保持不变。
6. 图面只保留资源角色、轴心坐标和本类必要读数。原生切图宽高、局部轴心、屏幕轴心、零位左上角、来源ID及进度参数记录在项目清单；数值均从本轮节点读取或计算，不照搬案例。

标注FRAME、实例、文字和线条关闭正式导出设置，不列入交付切图或混入背景、Active、AOD和缩略图。为核验图面可以临时输出该FRAME的真实1×PNG，作为评审证据保存；这不将标注设为正式导出资源。

## 各类图面与测量

| 类别 | 必要图面 | 几何与读数 |
| --- | --- | --- |
| 指针 `pointer` | 12点零位实例、水平guide、轴心坐标、红色竖向尺寸线及距离 | 从切图外框顶边到轴心，值为局部`pivot.y`，`measurement.kind=slice_top_to_pivot`；不是可见针尖到轴心，也不是整张切图高度。 |
| 旋转时间数字 `rotated_time` | 零位实例、水平guide、轴心坐标、红色竖向尺寸线及距离 | 从轴心到切图外框底边，值为母件高度减`pivot.y`，`measurement.kind=pivot_to_slice_bottom`；不套用指针的顶边测量。 |
| 进度 `progress` | 完整量程的真实资源实例、水平guide、轴心坐标、黄色起点线/读数、红色终点线/读数 | 圆弧或整圆采用真实中心和起止角；线性采用真实起止坐标。显示当前数值的短段不能冒充完整范围。 |

进度标注的角度以12点为0°、逆时针计角；`direction`单独记录真实进度增长方向（`clockwise`或`counterclockwise`），不改变指针旋转或业务数值映射的既有定义。起点用清楚的黄色（如`#FFBF00`或`#FFFF00`），终点用红色`#FF0000`；辅助线均无填充、2px描边。圆弧的起止线经过真实轴心及端点，读数来自源路径；不得从当前填充比例猜量程。整圆显式记录`full_turn:true`，起止重合也代表完整一周，标签排布保持可辨识，不移动真实端点来制造间隔。线性进度的`center`仅表示水平guide的布局基准，外部标签使用“参考基准 (x,y) px”；记录标注FRAME局部坐标的`start`、`end`，在实际两端标起止，不伪造圆心或角度。完整范围或轴心依据不足时记录`unverified`，先补来源证据。

## 参数与节点映射

项目清单保留原生切图宽高（`localWH`所指的母件宽高）、母件局部轴心`pivot`、目标表盘内轴心、零位左上角及正式显示来源。轴心不默认在切图中心；零位左上角由同一坐标系的`center - pivot`推导。标注FRAME中的`center`使用该FRAME局部坐标，并与正式表盘实际轴心一致。深浅底或AOD并排对照通过移动整个标注FRAME排布，不改变框内轴心，不把排布偏移写进母件`pivot`。

沿用生产规格`config.canvas`（兼容顶层`canvas`时须与其一致，缺失规格保持未验证）。快照使用`position_annotations`数组，每项采用本轮真实ID：

| 字段 | 含义 |
| --- | --- |
| `id`、`kind` | 本项目标注标识；`kind`为`pointer`、`progress`或`rotated_time`。 |
| `frame_id`、`master_id`、`instance_id` | 不导出的标注FRAME、当前母件、标注内1×实例。 |
| `source_instance_ids`、可选`source_master_ids` | 本次正式显示源实例，不填标注实例或隐藏对照。相同几何的亮屏/AOD可以共图；配对母件ID不同时以`source_master_ids:{"源实例ID":"实际母件ID"}`逐项绑定，仍核对各母件宽高及各来源轴心。不同进度母件分别核对完整路径。 |
| `pivot`、`center`、`background` | 母件局部轴心、标注FRAME内轴心和该FRAME实际底色。 |
| `measurement`、`axis_label_id` | 指针与旋转时间数字填写`measurement:{line_id,label_id,kind}`，并登记轴心坐标文字ID。`kind`按上表区分两种测量。 |
| 进度字段 | `shape:arc\|linear\|circle`、`source_path_id`、`direction`、`start_line_id`、`end_line_id`、`start_label_id`、`end_label_id`；弧形/整圆另有`start_angle`、`end_angle`，整圆需`full_turn:true`；线性用`start`、`end`两坐标。 |

采集配置`config.position_annotation_path_ids`登记全部标注LINE/VECTOR，保留同轮真实路径及描边；FRAME的`guides`自动采集并参与签名。参数文字不能代替母件、实例、路径和guide原始证据。旧`pointers[].annotation`仍可用于兼容原有图形，但不能代替新标注覆盖或当前图面的视觉核验，也不能据此在新标注中补回轴心圆、矩形尺寸线。

## 回读与图面评审

结构检查覆盖三类适用对象、母件引用与真实1×、正式显示来源、局部/屏幕轴心、零位变换、水平原生guide、实际底色、LINE/开放VECTOR及有效无填充描边（默认2px）、端点和读数、导出关闭。进度同时检查完整范围、起止颜色、计角与增长方向，不能因数字表盘没有指针就略过进度或旋转数字标注。

视觉报告的`position_annotation_review`数组逐`frame_id`建立记录，初始`status:unverified`、`evidence:null`、`notes:""`，`evidence:{path,sha256}`指向评审目录内当前真实1×PNG；`snapshot_fingerprint`由模板自动绑定当前快照，`notes`记录实际逐图评审说明；报告外层`snapshot_sha256`绑定本轮快照。实际查看每张图，核对元素及透明边缘、明暗底、线条与读数可辨识、无遮挡/裁切、起止语义和图面简洁后，分别记录`pass/fail/unverified`。原生guide还须回读真实属性，PNG或普通线条不能替代该证据。自动几何、PNG哈希、代理图面评审、用户验收和真机验证分别记录，不替用户宣称视觉通过。

母件尺寸、裁切、轴心、显示定位、进度量程或路径变化后，同步更新相关标注、清单及正式引用；受影响的旧快照、PNG与评审结论立即失效。重新采集、输出受影响FRAME的1×PNG并逐项评审，不用同名节点、相同ID或旧通过报告证明当前版本。
